## ✦ 什么是 Claudemusic

Claudemusic 是一款专为桌面打造的现代音乐播放器。

它本身不内置任何音源，所有能力通过插件扩展。界面属于你，内容由你决定。

---

## ✦ 功能

| | |
|---|---|
| 🎵 **本地播放** | 支持 MP3 / FLAC / WAV / M4A / OGG / OPUS 等主流格式 |
| 🧩 **插件扩展** | 通过插件接入第三方音源，搜索、播放、歌单导入一步到位 |
| 🎨 **主题定制** | 支持主题包更换外观，从配色到布局皆可自定义 |
| 📝 **桌面歌词** | 悬浮歌词、逐字滚动、锁定穿透，全屏工作也不打扰 |
| 💾 **数据备份** | 支持 WebDAV 同步歌单、设置与播放记录 |
| 🌙 **深色模式** | 跟随系统或手动切换，长时间使用不刺眼 |
| 🔒 **隐私优先** | 所有数据本地存储，不上传、不追踪、不分析 |

## ✦ 使用

### 首次启动

1. 下载并安装
2. 打开应用，进入 **插件管理** 添加你需要的插件
3. 进入 **设置 → 主题** 选择你喜欢的外观
4. 完成，开始使用

### 插件

Claudemusic 兼容 MusicFree 插件协议。插件可以从插件管理页添加，也可以手动导入。

### 主题

主题包可以在应用内的 **主题市场** 浏览和安装，也支持本地导入。

## ✦ 常见问题

**Q：Claudemusic 自带音源吗？**
A：不带。所有内容通过插件获取，请自行评估插件的安全性与合法性。

**Q：数据会上传到云端吗？**
A：不会。所有数据默认保存在本地，只有你主动开启 WebDAV 备份时才会同步。

**Q：会收费吗？**
A：不会。Claudemusic 完全免费。

**Q：遇到问题怎么办？**
A：在 [Issues](https://github.com/iLink-e/Claudemusic/issues) 里反馈，或通过官网联系。
